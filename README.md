# mallow
**an open source handheld game console powered by an esp32 s3.**

## key features (to be)
### custom games
easily flash your own game programmed in lua onto the game cartridge!<br>
the game cartridge should hold sprites and a main.lua file. at the moment, there's no support for saving game data to your cartridge directly. 

### controller save data
like the Nintendo Wii remote, the mallow controller has memory on it to save whatever data you want to it. the goal is to easily be able to transfer files from one mallow device to another, whether it be game save data, a drawing made on the device, or anything else you can think of that i cant.
